HTML

HTML semántico: la base que casi todos saltan

25 de noviembre de 2026 · 4 min de lectura

Cuando empecé a maquetar, todo era un <div> dentro de otro <div>. Funcionaba a la vista, pero ni los lectores de pantalla ni los buscadores entendían la página. El HTML semántico consiste en usar la etiqueta que describe el significado del contenido, no solo su aspecto.

Las etiquetas que más uso

  • <header> y <nav> para la cabecera y la navegación.
  • <main> para el contenido principal (uno por página).
  • <article> y <section> para agrupar contenido con sentido propio.
  • <figure> con <figcaption> para imágenes con pie. 
<article>
  <h1>Título</h1>
  <figure>
    <img src="foto.jpg" alt="Descripción útil">
    <figcaption>Pie de foto</figcaption>
  </figure>
</article>
El mejor texto alternativo es el que explica qué aporta la imagen, no solo qué se ve en ella.

Con estos cambios mis páginas mejoraron en accesibilidad y SEO sin tocar una sola línea de CSS.

CSS

Grid y Flexbox sin miedo

25 de noviembre de 2026 · 5 min de lectura

La pregunta típica es cuál usar. Mi regla: Flexbox para una dimensión (una fila o una columna) y Grid para dos dimensiones (filas y columnas a la vez).

Necesito… Uso
Barra de navegación Flexbox
Galería de tarjetas Grid
Centrar un elemento Flexbox o Grid

Responsive en una línea

Este blog usa una sola declaración para que las tarjetas se adapten a cualquier pantalla: 

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 1.2rem;
}

Sin media queries, sin JavaScript. También conviene usar variables CSS (--accent, --bg) para cambiar la paleta y soportar modo oscuro desde un único sitio.

Despliegue

De tu portátil a internet en 5 minutos

25 de noviembre de 2026 · 4 min de lectura

Un sitio estático es solo un conjunto de archivos, así que publicarlo es muy barato. Plataformas como Vercel, Netlify, GitHub Pages o Cloudflare lo hacen gratis y se integran con Git.

Pasos

  1. Crear un repositorio en GitHub con el index.html.
  2. Conectar el repositorio a la plataforma elegida.
  3. Cada git push a main genera un despliegue nuevo. 
git add .
git commit -m "Nueva entrada del blog"
git push origin main

Para probar algo rápido desde mi propio ordenador, también puedo exponerlo con un túnel temporal, aunque para algo permanente prefiero un despliegue de verdad.

Documentación del proyecto

1. Descripción

Blog estático con un archivo HTML, una hoja de estilos CSS y una imagen SVG independiente por entrada. No usa JavaScript ni dependencias externas.

2. Estructura

index.html
├─ css/style.css   Variables, layout, componentes, modo oscuro
└─ img/            Una imagen SVG por entrada (3 archivos)

Dentro de index.html:
├─ <header>  Cabecera y navegación
└─ <main>    Secciones: inicio, 3 entradas, proyectos, documentación

3. Cómo funciona la navegación

Cada vista es una <section id="..."> oculta con display:none. El selector :target muestra la que coincide con el hash de la URL (#entrada-2). Si no hay hash, body:not(:has(:target)) muestra el inicio. Así se pueden compartir enlaces directos y el botón Atrás funciona.

4. Decisiones de diseño

  • Tipografía: serif para el texto (lectura) y sans-serif para títulos y navegación.
  • Color: paleta cálida con acento rojo; modo oscuro automático con prefers-color-scheme.
  • Responsive: Grid con auto-fit y tablas con scroll horizontal.
  • Accesibilidad: HTML semántico, aria-label en imágenes, foco visible y contraste suficiente.

5. Cumplimiento de la rúbrica

Criterio Cómo se cumple
Mínimo 3 entradas Tres entradas con texto, imagen y pie de figura
Navegable Menú fijo, tarjetas, enlaces anterior/siguiente y volver
Diseño atractivo Tarjetas, ilustraciones, tipografía cuidada, modo oscuro
Documentación Esta página y los comentarios del código

6. Cómo añadir una entrada

Copiar un bloque <section class="page" id="entrada-N">, añadir su tarjeta en el inicio y enlazarla en la navegación. Para un blog más grande, el siguiente paso sería migrarlo a un generador estático como Jekyll o Eleventy y mantener las entradas en Markdown.
